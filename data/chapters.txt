# Chapters: which sets the game unlocks together, in order.
#
# A line starting with "Chapter" begins a new chapter; the rest of that line
# is its name. Under it, one set code per line (the code on the set's
# nameplate, e.g. FRA), in the order you want them. A new game opens
# Chapter 1; completing every binder in a chapter opens the next. Every set
# in a chapter unlocks when the chapter opens, each with a sealed booster
# box. Anything after a # is a comment, and blank lines don't matter. A set
# that isn't listed in any chapter gets a chapter of its own after these.
