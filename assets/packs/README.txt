Booster pack wrapper art, one pair of images per set, named by the set's
code in capitals (as in the card data, e.g. KTK):

  KTK.png        the front of the wrapper
  KTK_back.png   the back of the wrapper (optional)

Each can be a .png or a .jpg (or .jpeg or .webp). Use the pack's shape:
portrait, 66 x 117 mm, e.g. 528 x 936 px. The whole image covers the face,
crimped seams included (the top and bottom 7.5% get the crimps' silver
ridges over them, and the tear runs about 10% down from the top). The foil
sheen and crinkle are added by the shader, so flat art works best.

A set with no front image gets the stand-in wrapper: the set's colour with
its name and code lettered on. Images are read when the game starts, so
restart it to see a change.
