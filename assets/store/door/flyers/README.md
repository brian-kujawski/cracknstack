# Door flyers

The front door's glass is papered with letter-size flyers (`ShopDoor.FLYERS` in `scripts/store/shop_door.gd`). Each one is its own mesh and material. To give flyer number NN a picture, save it here as `flyer_NN.png` (or `.jpg` / `.webp`), numbered from `01` in `FLYERS` order, and open the project in the editor once so Godot imports it.

Pictures fill the whole sheet, so draw them at letter proportions: portrait 8.5 × 11 (e.g. 850 × 1100 px), except flyers 04, 05, 11, 12, 15 and 16, which hang landscape (11 × 8.5, e.g. 1100 × 850 px). Until a picture is added, a flyer is blank coloured paper.

The game's own Fan Content rules apply: invented events and art you made or have the rights to, no Wizards logos.
